# Style System

Review at 100 × 100 px. Use only BLUE `#2E3A4D`, TAUPE `#C4C1B4`, PAPER
`#F2F0E9`, and INK `#0D0D0D`; transparent variants are allowed.

The pack contains three heart variants plus `ИРА` inside a BLUE heart.
`ИРА` is PAPER only and has no outline. Preserve the existing four heart
animations rather than importing unrelated icon styles.
