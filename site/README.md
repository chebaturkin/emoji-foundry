# Signal

`site` содержит самостоятельную статическую мастерскую Signal. Фонди — её
персонаж и проводник: четыре сцены помогают собрать жест, дать паузу,
упаковать записку и сыграть ритм.

Нумерованная навигация переключает сцены. У каждой сцены своя рабочая
поверхность; подписи повторения и сообщения о действиях учитывают её режим.

## Запуск

Из корня репозитория:

```sh
python3 site/build.py
python3 site/serve.py --port 8799
```

Откройте <http://127.0.0.1:8799/>. Сборка полностью локальная, не читает
файлы за пределами репозитория и пишет результат в `site/public`.

## Архитектура

- `sections/workshop.html` — семантическая разметка сцен и доступные кнопки;
- `sections/workshop.css` — визуальные токены, адаптивность и motion;
- `sections/workshop.js` — реакции Фонди, действия сцен, экспорт и hash-share;
- `lib/workshop-state.js` — чистые функции нормализации и кодирования состояния;
- `base.css` — базовая типографика и общие переменные;
- `build.py` — сборка страницы, маскота, favicon и локальных шрифтов.

Runtime-дерево содержит только локальные медиа Signal: `assets/mascot`,
`assets/favicons`, `assets/fonts`, `site.css` и `site.js`. Старые экспортные
каталоги и сторонние интеграции в сборку не входят.

## Приватность

Состояние живёт в URL-хэше текущей страницы. Signal не делает сетевых
запросов, не требует аккаунта или ключа API и не собирает аналитику. Экспорт
создаёт файл на устройстве пользователя.

## Проверка

```sh
python3 -m pytest -q site/tests
node --test site/tests/test_workshop_state.mjs site/tests/test_workshop_contract.mjs
```

После запуска сервера можно выполнить `python3 site/verify.py` для проверки
сцен, клавиатуры, адаптивных размеров, reduced motion и локальных медиа.
