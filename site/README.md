# Fondy workshop

Небольшая статическая мастерская о четырёх сердечных жестах. Фонди помогает
собрать сигнал, упаковать короткую записку, выдержать паузу и сыграть ритм.
Состояние хранится в адресной строке; сервер, аккаунт и API-ключи не нужны.

## Запуск

Из корня репозитория:

```sh
python3 site/build.py
python3 site/serve.py --port 8799
```

Откройте <http://127.0.0.1:8799/>. Сборщик пишет готовый статический сайт в
`site/public`. Все ссылки внутри него относительные, поэтому папку можно
открыть из подпути GitHub Pages или отдать любому статическому хостингу.

## Что собирается

- `site/public/index.html` — мастерская и её четыре сцены;
- `site/public/assets` — шрифты, маскот, фирменные SVG и четыре сердца в PNG,
  GIF и WebM;
- `site/public/cases` — три демонстрационных кейса, если их исходники есть в
  рабочей копии.

Кнопка «скачать открытку» собирает отдельный HTML с уже встроенными Фонди,
сердцами и шрифтами. Его можно открыть без сервера; это сохранённый результат
сцены, а не новая копия мастерской.

Кейс-архив необязателен: если фрагментов кейсов нет, сборка всё равно создаёт
полный workshop-бандл. Сборка останавливается до очистки `site/public`, если
не хватает обязательного источника, и явно называет отсутствующий путь.

## Исходники и границы

- `sections/workshop.html`, `sections/workshop.css`, `sections/workshop.js` —
  разметка, движение и действия мастерской;
- `lib/workshop-state.js` — чистый код кодирования состояния в `#v1=...`;
- `base.css` — общие токены и типографика;
- `brand-kit/assets` и `brand-kit/fonts` — исходные фирменные медиа;
- `../Чебутуркин Emoji/01-ready-to-upload`, `../Чебутуркин Emoji/02-static-png`,
  `../Чебутуркин Emoji/03-previews` — канонические релизные файлы четырёх
  Telegram-эмодзи. Для другого расположения задайте `EMOJI_PACK_ROOT`.

`site/assets` и `site/public` содержат результаты сборки. Не редактируйте их
вручную: повторите `python3 site/build.py` после изменения исходников. Сборщик
читает текст только в UTF-8 и не обращается к сети.

## Проверка

```sh
python3 -m pytest -q site/tests
node --test site/tests/test_workshop_state.mjs site/tests/test_workshop_contract.mjs
```

Для браузерной проверки сначала соберите сайт и запустите локальный сервер,
затем выполните `python3 site/verify.py`. Скрипт проверяет четыре сцены,
клавиатурный доступ, локальные медиа и режим reduced motion.
