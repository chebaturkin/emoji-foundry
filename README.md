# Signal · маленькая мастерская жестов

Signal — самостоятельный визуальный pet-проект Тимофея Чебатуркина. Фонди
помогает собрать короткий жест из простых действий: выбрать сигнал, выдержать
паузу, написать записку или сыграть ритм. Страница живёт целиком в браузере:
без аккаунтов, сервера, аналитики и внешнего API.

## Запуск

Нужны Python 3.11+ и Node.js 20+ только для проверок.

```bash
python3 site/build.py
python3 site/serve.py --port 8799
```

Откройте <http://127.0.0.1:8799/>. Сборка создаёт чистую статическую папку
`site/public`; её можно отдать любому хостингу статических файлов или открыть
через локальный сервер.

## Что внутри

- `site/sections/workshop.*` — разметка, motion и действия интерфейса;
- `site/lib/workshop-state.js` — проверка состояния и кодирование в URL-хэш;
- `site/build.py` — повторяемая сборка без сети;
- `site/serve.py` — безопасный локальный просмотр;
- `brand-kit/assets/mascot` — исходники Фонди;
- `brand-kit/fonts` — локальные шрифты и их лицензии.

Signal сохраняет состояние только в адресной строке. Кнопка экспорта собирает
PNG или автономную HTML-открытку с текущим жестом. Данные не отправляются на
сервер и не записываются в базу.

## Проверка

```bash
python3 site/build.py
python3 -m pytest -q site/tests
node --test site/tests/test_workshop_state.mjs site/tests/test_workshop_contract.mjs
```

Для браузерного smoke-теста запустите сервер и выполните `python3 site/verify.py`.
