# Telegram Emoji Ira Heart and Brand Blue Design

## Цель

Добавить в существующий анимированный Telegram emoji pack новый персональный символ `27-ira-heart` и удалить голубой акцент `#5B8BC4` из действующих покадровых сценариев.

## Визуальная композиция `27-ira-heart`

Используется утвержденный вариант C2:

- рукописное слово `ИРА` располагается в центре
- сердце собирается из двух отдельных незамкнутых жестов вокруг имени
- верхняя линия формирует две дуги сердца
- нижняя линия формирует сходящиеся к нижней точке половины
- основной и единственный синий цвет: `#2E3A4D`, RGBA `(46, 58, 77, 255)`
- голубой цвет и светлая внутренняя линия сердца не используются
- буквы строятся собственной векторной геометрией без системного шрифта
- прозрачный фон сохраняется на всех кадрах

## Сценарий анимации

Цикл длится 42 кадра при 30 FPS, общая длительность 1,4 секунды.

1. Буквы `И`, `Р`, `А` рисуются слева направо отдельными мазками с переменным нажимом.
2. Верхняя и нижняя части сердца начинают рисоваться с небольшой задержкой и обнимают готовое имя.
3. В момент визуального замыкания две линии дают короткую локальную отдачу в точках сближения.
4. Композиция удерживается достаточно долго для чтения в миниатюре.
5. Сердце втягивается первым, затем буквы сворачиваются справа налево.
6. Первый и последний кадры полностью прозрачные.

Запрещены общий fade, масштабирование всей композиции и простое покачивание готового символа.

## Замена голубого акцента

Голубой RGBA `(91, 139, 196, ...)` заменяется фирменным синим RGB `(46, 58, 77)` в следующих сценариях:

- `06-spark`
- `07-lightning`
- `09-idea`
- `11-eye`
- `14-sad`
- `20-check`
- `03-heart-open`

Исходная прозрачность каждого слоя сохраняется. Геометрия, тайминг и механика этих семи анимаций не меняются.

## Интеграция

- новый сценарий создается как отдельный `FrameMotionSpec` в `frame_motions/m27_ira_heart.py`
- реестр расширяется до 27 элементов
- `27-ira-heart` получает теги `soft` и `tactile`
- для узкой пересборки используется существующая выборка по имени `27-ira-heart`
- готовый файл сохраняется как `upload/27-ira-heart.webm`
- существующие семь WebM после цветовой замены пересобираются из прежних кадровых сценариев

## Технический контракт

- 100 x 100 px
- 42 кадра
- 30 FPS
- VP9 WebM с прозрачностью
- без звука
- не больше 64 KiB по внутреннему лимиту проекта
- контент внутри безопасной зоны 8 px
- четкое чтение букв `ИРА` в исходном размере

## Проверка

- поведенческие тесты фиксируют порядок отрисовки букв и сердца
- тест палитры запрещает RGB `(91, 139, 196)` во всех зарегистрированных кадрах
- тест реестра ожидает ровно 27 уникальных сценариев
- новый символ проверяется на пустые крайние кадры и безопасную зону
- выполняется сборка нового WebM и семи обновленных WebM
- выполняются полный `pytest` и полный Telegram-валидатор
- визуальная приемка проводится по настоящему WebM и ключевым кадрам на темном и светлом фоне

## Восстановимость

После успешной полной проверки создается один новый source-checkpoint полного пака из 27 эмодзи. Предыдущий checkpoint пака из 26 эмодзи сохраняется без изменений.
