# Telegram Emoji Beige Ira and Final Handoff Package Design

## Цель

Доработать персональный эмодзи `27-ira-heart` утвержденным бежевым вариантом A и создать на Desktop итоговую переносимую папку полного пака. Папка должна подходить для загрузки в Telegram, просмотра, статичного использования и дальнейшего точечного редактирования другой ИИ без восстановления контекста текущего диалога.

## Доработка `27-ira-heart`

Утвержден вариант A:

- сердце сохраняет фирменный синий `#2E3A4D`
- каждая буква `ИРА` сначала рисуется синим основным мазком
- поверх синего мазка с задержкой в один кадр проходит более тонкий бежевый штрих `#C4C1B4`
- синяя основа остается видимой по краям букв и связывает имя с сердцем
- бежевый применяется только к буквам
- геометрия сердца, тайминг 42 кадра и существующий порядок появления не меняются
- общий fade, масштабирование всей композиции и новые декоративные части не добавляются

## Статичные версии

Для каждого из 27 эмодзи создается чистая статичная версия:

- `100 x 100 px`
- RGBA PNG
- прозрачный фон
- полностью сформированный основной символ
- без временных искр, ударных лучей, частиц и переходных деформаций
- для `01-26` источником служит утвержденный raster master, уменьшенный качественным LANCZOS
- для `27-ira-heart` используется отдельный `draw_static_frame`, который рисует готовое сердце и двухцветное имя без closure accents

Дополнительно сохраняется редактируемая версия той же композиции в `400 x 400 px`. Для `01-26` она создается из master PNG, для `27-ira-heart` из векторного `draw_static_frame`.

## Готовые анимации

`01-ready-to-upload/animated-webm` содержит ровно 27 текущих проверенных WebM. В этой папке нет GIF, кадров, исходников или посторонних файлов, поэтому ее можно целиком использовать как источник для загрузки в `@Stickers`.

## Редактируемый проект

`04-editable-project` является самостоятельной копией рабочей среды без абсолютной зависимости от исходной папки на Desktop.

В копию входят:

- все покадровые сценарии и общий renderer
- 26 raster master PNG
- все итоговые прозрачные кадры каждой анимации
- копии готовых WebM и preview внутри проекта для локальной работы валидатора и preview builder
- тесты и Telegram-валидатор
- bundled ffmpeg для macOS arm64
- скрипты сборки, preview и экспорта
- утвержденные design specs и implementation plans этого пака
- pinned `requirements.txt` для Python-зависимостей

Не копируются checkpoints, `__pycache__`, временные QA-файлы и `.superpowers`.

## AI handoff

### `START_HERE.md`

Коротко объясняет, что находится в каждой папке, какие файлы являются готовыми, а какие исходными, и с какого документа начинать редактирование.

### `AI_EDITING_PROMPT.md`

Готовый промпт для передачи другой ИИ. Он требует:

- сначала прочитать манифест и архитектуру
- менять только указанный пользователем эмодзи
- не изменять общую палитру без явного запроса
- писать регрессионный тест до изменения поведения
- пересобирать только измененный stem
- запускать узкий валидатор, затем полный gate
- сохранять 100 x 100 px, прозрачность, VP9, 30 FPS, safe area 8 px и лимит 64 KiB

### `emoji-manifest.json`

Для каждого эмодзи содержит:

- порядковый номер
- `stem`
- понятное название
- категорию и теги
- количество кадров, FPS и длительность
- тип источника статичной версии: `master` либо `vector_static_renderer`
- краткую идею анимации
- путь к source module
- путь к master PNG либо `null` для полностью векторного сценария
- пути к WebM, статичному PNG, GIF и каталогу кадров

### `PALETTE.md`

Фиксирует:

- brand blue `#2E3A4D`, RGB `(46, 58, 77)`
- taupe beige `#C4C1B4`, RGB `(196, 193, 180)`
- paper `#F2F0E9`, RGB `(242, 240, 233)`
- ink `#0D0D0D`, RGB `(13, 13, 13)`
- запрет голубого `#5B8BC4`, RGB `(91, 139, 196)` в зарегистрированных сценариях

## Экспортер

В рабочий проект добавляется `export_final_package.py`. Он:

1. проверяет наличие 27 зарегистрированных сценариев
2. экспортирует master-based статику `01-26` и vector-based статику `27`
3. сохраняет 100 x 100 и 400 x 400 PNG
4. копирует готовые WebM, GIF, contact sheets, исходники, кадры, masters, tests и tools
5. создает `emoji-manifest.json` и handoff-документы
6. отклоняет неизвестные или лишние WebM
7. создает `SHA256SUMS` после полной сборки папки

Экспортер не удаляет существующие пользовательские каталоги. Если целевая папка уже существует, он завершает работу с понятной ошибкой. Повторный экспорт выполняется только в новый пустой путь либо после явного удаления пользователем предыдущей папки.

## Проверка

- поведенческий тест подтверждает задержку бежевого штриха относительно синего
- тест палитры подтверждает наличие beige и brand blue в сформированном `27-ira-heart`
- тест экспортера проверяет структуру папки на временном каталоге
- тест манифеста требует ровно 27 уникальных записей и существование всех заявленных файлов
- тест статичных PNG проверяет RGBA, размеры, прозрачный фон и safe area
- полный `pytest` проходит без ошибок
- полный Telegram-валидатор принимает 27 WebM
- SHA-256 проверка итоговой папки проходит без ошибок
- статичный contact sheet всех 27 PNG визуально проверяется на светлом и темном фоне

## Результат

Пользователь получает одну итоговую папку на Desktop. Для загрузки используется `01-ready-to-upload/animated-webm`. Для передачи другой ИИ передается вся папка вместе с указанием начать с `05-ai-handoff/START_HERE.md`.
