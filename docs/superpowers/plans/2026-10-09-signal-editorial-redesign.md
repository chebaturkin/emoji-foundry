# Signal editorial redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rework the Signal workshop's authored HTML, CSS, and dynamic copy into a distinctive editorial workbench while preserving all scenes, state, exports, keyboard access, and reduced-motion behavior.

**Architecture:** Keep the current static build and single workshop module. Replace the authored shell and visual token layer in `workshop.html`/`workshop.css`, then update only user-facing strings and dynamic labels in `workshop.js`. The state codec and event model remain unchanged; verification happens through the existing build and test commands plus a responsive browser smoke check.

**Tech Stack:** Static HTML, CSS, vanilla JavaScript, local SVG mascot, local Dela/Onest fonts, Python build, Node tests.

---

### Task 1: Rewrite the authored structure and interface copy

**Files:**
- Modify: `site/sections/workshop.html`

- [ ] Replace the header note, hero lede/instruction/caption, status text, scene index labels, scene descriptions, token subtitles, empty states, action labels, privacy note, and footer copy with the concrete strings in the design spec.
- [ ] Keep every existing `data-*` hook, tab/tabpanel relationship, form field, action button, and local asset path intact.
- [ ] Add non-color active cues to the scene index markup (for example an `aria-current`-compatible visible marker) without changing the JS contract.
- [ ] Preserve meaningful `aria-label`, `aria-describedby`, and `role` attributes; improve the rhythm timeline to expose its changing sequence as a status/group without removing the visual timeline.
- [ ] Run `node --test site/tests/test_workshop_contract.mjs` and confirm only intentional copy-sensitive assertions need adjustment (there should be none for the current contract).

### Task 2: Replace the card-heavy visual system with an editorial workbench

**Files:**
- Modify: `site/sections/workshop.css`

- [ ] Rebuild the base tokens and layout rules around ruled lines, small radii, offset borders, and generous editorial spacing; remove the black active pill navigation and repeated pill-only action treatment.
- [ ] Redesign the hero as an asymmetric two-column composition with a framed Fondy illustration, a smaller measured display title, an annotation, and fewer decorative circles.
- [ ] Redesign scene navigation as a compact table-of-contents row/list with an ink underline and orange index marker; keep it responsive at 800px and 520px.
- [ ] Give each scene one clear work surface while preserving its existing controls: signal board, pause sheet, letter desk, and rhythm strip. Keep token glyphs and the envelope readable and keep Fondy visible in the hero plus the scene where it clarifies feedback.
- [ ] Add robust focus, hover, active, and reduced-motion states. Ensure orange text has sufficient contrast or a second visual cue; do not rely on color alone for active state.
- [ ] Validate overflow and layout at 320, 390, 768, 1024, and 1440px with `python3 site/verify.py` after the HTML/JS changes land.

### Task 3: Align dynamic status, controls, and export copy

**Files:**
- Modify: `site/sections/workshop.js`

- [ ] Update `announce()` strings for pause completion/holding, letter completion, link copying, and repeat/reset actions so they describe the real next step.

- [ ] Update exported SVG labels and descriptions to the same lower-case concrete voice; remove any claim that a note can be sent or shared and describe local browser output instead.
- [ ] Keep PNG fallback, standalone HTML generation, URL hash state, and reduced-motion timing unchanged.
- [ ] Run the Node state and contract tests after the JS edits.
