# Безопасность

Signal — статический сайт: серверной части, базы данных, авторизации и
внешних API здесь нет. Браузер хранит состояние только в URL-хэше и не
отправляет его владельцу проекта.

Если вы нашли в репозитории секрет, персональные данные или уязвимость,
напишите автору напрямую через [chebaturkin.com](https://chebaturkin.com).
Пожалуйста, не публикуйте детали до того, как проблема будет исправлена.
